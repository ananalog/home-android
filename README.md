# home-android

Android-приложение системы [Home](https://github.com/ananalog/home) для настройки устройств по Bluetooth:
Wi-Fi, DHCP/статический IP, адрес сервера, сброс настроек, откат к заводской прошивке, OTA по BLE.
Проект — [`home/doc/04-android.md`](https://github.com/ananalog/home/blob/main/doc/04-android.md).

Kotlin, Jetpack Compose, Nordic Android BLE Library. Протокол — сабмодуль `external/home-protocol`.
